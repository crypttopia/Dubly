# حریم خصوصی Dubly

آخرین به‌روزرسانی: ۵ مهر ۱۴۰۵. این متن رفتار نسخهٔ 0.9.28 افزونه را توضیح می‌دهد.

Dubly افزونه‌ای مستقل برای دوبلهٔ زندهٔ صدای تب انتخاب‌شده و تایپ صوتی است و با کلید شخصی Google Gemini API شما کار می‌کند. تایپ صوتی فقط پس از زدن «شروع» در کنترل شناور، صدای میکروفن را مستقیماً برای تبدیل زندهٔ گفتار به متن به Gemini Transcribe Live می‌فرستد.

## چه چیزی پردازش و ارسال می‌شود؟

پس از زدن «شروع»، صدای تب انتخاب‌شده از طریق اتصال رمزگذاری‌شدهٔ WebSocket مستقیماً به Google Gemini API فرستاده می‌شود. کلید API برای احراز همان اتصال استفاده می‌شود. تصویر ویدیو و تاریخچهٔ مرور برای ترجمه ارسال نمی‌شوند. Dubly سرور واسطهٔ ترجمه یا ابزار ارسال آمار ندارد. بستن پنجرهٔ کوچک افزونه جلسه را تمام نمی‌کند؛ برای قطع ارسال صدا «توقف» را بزنید یا تب منبع را ببندید.

متن ترجمه و عنوان تب ممکن است در طول جلسه داخل افزونه نمایش داده شوند. متن ترجمه فقط در حافظهٔ همان جلسه می‌ماند. Dubly فایل صدا یا ویدیو، متن زیرنویس، عنوان، دامنه یا آدرس کامل صفحات را در سابقهٔ فعالیت ذخیره نمی‌کند. در صورت فعال‌کردن زیرنویس شناور، متن ترجمه برای نمایش به اسکریپت ایزولهٔ همان تب، از جمله صفحه‌های فقط صوتی، فرستاده می‌شود؛ کلید API به صفحهٔ وب داده نمی‌شود.

## تایپ صوتی

دسترسی اختیاری صفحات وب فقط پس از زدن **فعال‌کردن تایپ صوتی** درخواست می‌شود. این دسترسی به‌صورت محلی برای نمایش کنترل شناور، تشخیص فیلد قابل‌ویرایش فعال و درج متن در `input`، `textarea` یا `contenteditable` استفاده می‌شود. از آن برای مانیتورکردن تاریخچهٔ مرور یا فعالیت‌های نامرتبط کاربر استفاده نمی‌شود. کنترل فقط به همان تبی متصل می‌ماند که آن را فعال کرده‌اید.

بررسی یک‌بارهٔ اجازه در Chrome ممکن است میکروفن را لحظه‌ای باز و بلافاصله ببندد؛ در این مرحله هیچ صوتی به گوگل ارسال نمی‌شود. دریافت و ارسال پیوستهٔ میکروفن فقط پس از زدن **شروع** روی کنترل شناور آغاز می‌شود و با **توقف** یا بستن کنترل پایان می‌یابد.

هنگام ضبط، صدای میکروفن با کلید API خودتان و از طریق WebSocket رمزگذاری‌شده مستقیماً برای تبدیل گفتار به متن به Google Gemini Transcribe Live فرستاده می‌شود. متن برگشتی فقط در حافظهٔ کنترل شناور می‌ماند تا آن را درج، کپی، حذف یا کنترل را ببندید. صدای میکروفن، متن تایپ صوتی و کلید API از سرورهای Dubly عبور نمی‌کنند و روی آن‌ها ذخیره نمی‌شوند؛ Dubly برای این قابلیت سرور واسطه ندارد. پس از درج متن در یک سایت، پردازش آن متن تابع سیاست حریم خصوصی همان سایت است.

## مجوزهای Chrome

- **activeTab:** پس از اقدام صریح شما، دسترسی موقت لازم برای شروع قابلیت روی تب فعال را می‌دهد.
- **دسترسی اختیاری سایت‌ها (`http://*/*` و `https://*/*`):** فقط پس از اقدام شما برای فعال‌کردن تایپ صوتی درخواست می‌شود تا کنترل در همان تب نمایش داده و پس از جابه‌جایی بازیابی شود و متن را در فیلد فعال درج کند. این اجازه را می‌توانید از Site access در Chrome لغو کنید.
- **tabCapture:** صدای همان تب را در زمان جلسهٔ دوبله دریافت می‌کند.
- **دسترسی میکروفن:** پس از فعال‌سازی تایپ صوتی، Chrome اجازه را درخواست می‌کند. بررسی اجازه ممکن است میکروفن را لحظه‌ای باز کند، اما ارسال صدا فقط پس از زدن «شروع» روی کنترل شناور و فقط هنگام ضبط انجام می‌شود.
- **offscreen:** سند مخفی Chrome را برای پردازش صدای تب، پخش دوبله و اتصال مستقیم صدای میکروفن به سرویس رونویسی گوگل، حتی پس از بسته‌شدن پنجرهٔ افزونه، اجرا می‌کند.
- **storage:** کلید API، تنظیمات و سابقهٔ فعالیت اختیاری دوبله را روی دستگاه نگه می‌دارد. متن تایپ صوتی در storage افزونه نوشته نمی‌شود.
- **scripting:** پس از فعال‌سازی شما، زیرنویس یا کنترل تایپ صوتی را به تب انتخاب‌شده اضافه می‌کند، فیلد فعال `input`، `textarea` یا `contenteditable` را برای درج مشخص می‌کند و ممکن است برای هماهنگی آغاز دوبله، پخش‌کننده را یک‌بار کوتاه متوقف و دوباره پخش کند. از دسترسی سایت‌ها برای مانیتورکردن تاریخچهٔ مرور یا فعالیت‌های نامرتبط استفاده نمی‌شود.

تنها مقصد شبکهٔ افزونه `https://generativelanguage.googleapis.com/*` است و اتصال Gemini از نشانی امن `wss://generativelanguage.googleapis.com` برقرار می‌شود. دسترسی اختیاری صفحات وب فقط برای نمایش محلی کنترل تایپ صوتی و درج متن استفاده می‌شود و مقصد شبکهٔ جدیدی اضافه نمی‌کند. کنترل فقط به همان تبی متصل می‌ماند که آن را فعال کرده‌اید. صفحات داخلی Chrome، Chrome Web Store و بعضی پخش‌کننده‌های محافظت‌شده پشتیبانی نمی‌شوند.

## اطلاعات ذخیره‌شده روی دستگاه

کلید Gemini و ترجیح‌های شما، از جمله زبان و میزان صدا، در حافظهٔ محلی افزونه ذخیره می‌شوند تا پس از بستن مرورگر یا خاموش‌کردن دستگاه باقی بمانند. این داده‌ها با حساب Chrome همگام نمی‌شوند. حافظهٔ محلی افزونه گاوصندوق رمزگذاری‌شدهٔ اختصاصی نیست؛ از دستگاه و کلید خود محافظت کنید. کلید را می‌توانید در تنظیمات عوض یا حذف کنید.

«فعالیت من» به‌طور پیش‌فرض مدت ارسال صدای تب در جلسهٔ دوبله، تاریخ محلی، زبان مقصد و شناسهٔ تصادفی جلسه را تا ۳۶۶ روز روی همین دستگاه نگه می‌دارد. صدا و متن تایپ صوتی در «فعالیت من» ثبت نمی‌شوند. این زمان شامل سکوت تب است و معادل مدت گفتار ترجمه‌شده یا هزینهٔ گوگل نیست. می‌توانید ثبت فعالیت را خاموش یا کل سابقه را پاک کنید. حذف افزونه، داده‌های محلی مدیریت‌شدهٔ آن را مطابق رفتار ذخیره‌سازی Chrome حذف می‌کند.

## گوگل، استفادهٔ محدود و حمایت مالی

گوگل صدای تب را برای ترجمه و صدای میکروفن را برای رونویسی، همراه درخواست‌های API مربوط، بر اساس شرایط و سیاست‌های خودش پردازش می‌کند. قواعد استفاده از داده ممکن است با توجه به سرویس و نوع حساب شما متفاوت باشد. پیش از ارسال محتوای حساس، [شرایط Gemini API](https://ai.google.dev/gemini-api/terms) و [سیاست حریم خصوصی گوگل](https://policies.google.com/privacy) را بخوانید.

Dubly داده‌های کاربر را نمی‌فروشد و از سابقهٔ محلی برای تبلیغات استفاده نمی‌کند. استفاده از اطلاعات دریافتی از APIهای گوگل مطابق Chrome Web Store User Data Policy، از جمله الزامات Limited Use، خواهد بود.

حمایت مالی با رمزارز اختیاری است. تراکنش‌های بلاک‌چین ممکن است عمومی باشند و سرویس‌های کیف پول سیاست‌های خود را دارند. حمایت مالی قابلیتی را فعال نمی‌کند.
