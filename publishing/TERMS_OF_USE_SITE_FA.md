# شرایط استفاده از Dubly

آخرین به‌روزرسانی: ۵ مهر ۱۴۰۵. این شرایط نسخهٔ 0.9.28 افزونه را توضیح می‌دهد.

## افزونه و کلید API

Dubly افزونهٔ رایگان Chrome برای دوبلهٔ زندهٔ صدای تب انتخاب‌شده و تایپ صوتی اختیاری است. شما کلید معتبر Google Gemini API خودتان را وارد می‌کنید. دسترسی به مدل، مناطق مجاز، سهمیه و هزینه‌های احتمالی را گوگل برای حساب شما تعیین می‌کند. رایگان‌بودن Dubly به معنی سهمیهٔ نامحدود یا رایگان‌بودن همیشگی Gemini API نیست.

## شروع و پایان جلسه

با زدن «شروع»، به Dubly دستور می‌دهید صدای تب فعال را دریافت و با کلید شما مستقیماً برای پردازش به Google Gemini API ارسال کند. این کار به همان تب و همان جلسه مربوط است. بستن پنجرهٔ کوچک افزونه ارسال را متوقف نمی‌کند؛ برای پایان «توقف» را بزنید یا تب منبع را ببندید. زیرنویس شناور، در صورت انتخاب، متن ترجمه را بدون پخش صدای دوبله روی همان تب برای ویدیو، پخش‌کنندهٔ صوتی یا پخش زنده نمایش می‌دهد و از همان اتصال Gemini استفاده می‌کند.

دسترسی صفحات وب برای تایپ صوتی فقط پس از اقدام شما برای فعال‌کردن آن درخواست می‌شود و برای نمایش کنترل شناور و درج متن در فیلد قابل‌ویرایش فعال است. ارسال میکروفن فقط پس از زدن «شروع» روی همان کنترل آغاز می‌شود. صدای میکروفن و کلید شما مستقیماً به Google Gemini Transcribe Live می‌روند و متن برگشتی تا زمان درج، کپی، حذف یا بستن در کنترل محلی می‌ماند. این موارد از سرورهای Dubly عبور نمی‌کنند و روی آن‌ها ذخیره نمی‌شوند.

## مسئولیت شما

فقط محتوایی را پردازش و ارسال کنید که حق استفاده از آن را دارید. حق نشر، قوانین سایت مبدأ، شرایط گوگل، محدودیت‌های سنی و منطقه‌ای و سهمیه یا هزینهٔ حساب API خود را رعایت کنید. کلید API را در اختیار دیگران نگذارید و از Dubly برای کار غیرقانونی استفاده نکنید.

## دسترسی و دقت

ترجمه ممکن است اشتباه، ناقص یا با تأخیر باشد. برای تصمیم‌های پزشکی، حقوقی، مالی یا سایر موضوعات حساس فقط به آن تکیه نکنید. مدل‌های پیش‌نمایش و دسترسی سرویس گوگل ممکن است تغییر کنند. Dubly برای جبران تأخیر اولیه ممکن است پخش‌کنندهٔ فعال را یک‌بار کوتاه متوقف کند، اما کارکرد روی همهٔ سایت‌ها و پخش‌کننده‌ها، همگام‌سازی لب یا جداسازی موسیقی را تضمین نمی‌کند.

## حمایت مالی و استقلال

حمایت مالی اختیاری است؛ خرید سرویس، فعال‌کردن قابلیت یا تعهد به امکانات آینده نیست. پیش از انتقال، آدرس و شبکهٔ بلاک‌چین را بررسی کنید؛ انتقال‌ها معمولاً برگشت‌پذیر نیستند. این متن حقوق الزامی مصرف‌کننده را محدود نمی‌کند.

Dubly مستقل است و وابسته به Google LLC یا مورد تأیید و حمایت آن نیست. Google، Gemini و Google AI Studio نام‌های تجاری Google LLC هستند.

## حریم خصوصی و تماس

برای جزئیات مجوزها، ذخیرهٔ داده و پردازش گوگل، [سیاست حریم خصوصی Dubly](https://sites.google.com/view/dubly-privacy-policy) را بخوانید. برای پرسش یا پشتیبانی از `dubly.support@gmail.com` یا لینک پشتیبانی داخل افزونه استفاده کنید.
